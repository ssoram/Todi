불러오기전체 선택/해제
추가·완료·수정한 내용이 다른 컴퓨터에도 자동으로 반영돼요. 두 컴퓨터에 같은 동기화 코드를 넣으면 연결돼요. 주고받는 내용은 이 코드로 암호화돼서, 코드를 모르는 사람은 (클라우드 회사도) 내용을 볼 수 없어요.
다른 컴퓨터에서 이미 코드를 만들었다면 그 코드를 넣으세요.
동기화 코드
이 코드를 다른 컴퓨터의 Todi → 설정 → 자동 동기화에 넣으세요. 코드는 다른 사람에게 알려 주지 마세요.
보낼 카테고리전체 선택/해제
체크한 카테고리를 다른 컴퓨터로 보내고, 그쪽에서 바뀐 내용도 받아 와요. 받기만 할 컴퓨터는 고르지 않아도 돼요 — 다른 컴퓨터가 보낸 카테고리는 여기에 자동으로 추가되고 체크돼요. 받고 싶지 않은 카테고리는 체크를 끄세요.
방법 (하나만 켜도 되고, 둘 다 켜도 돼요)
다른 컴퓨터를 아직 찾지 못했어요. 이렇게 확인해 보세요.
① 두 컴퓨터 모두 새 버전 Todi가 켜져 있고, 같은 코드에 같은 와이파이가 켜져 있는지
② 두 컴퓨터가 같은 공유기에 연결돼 있는지 (유선·무선이 섞여 있어도 괜찮아요. 손님용 와이파이는 서로 안 보일 수 있어요)
③ Windows 방화벽에서 Todi가 허용돼 있는지 — 방화벽 창에서 취소를 눌렀다면: 설정 → 개인 정보 및 보안 → Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용에서 Todi의 개인·공용을 모두 체크
④ 그래도 안 되면 아래 칸에 다른 컴퓨터에 표시된 주소를 넣어 보세요. 한쪽에만 넣으면 되는데, 응답이 없다고 나오면 반대쪽 컴퓨터에 넣어 보세요. (모뎀과 공유기가 따로 있는 집처럼 두 컴퓨터가 다른 공유기에 연결돼 있으면, 한쪽 방향으로만 연결될 수 있어요)
회사·공용 PC처럼 다른 사람이 볼 수 있는 곳에서, 고른 카테고리를 비밀번호로 잠가 숨겨요. 잠기면 그 카테고리는 모든 창에서 사라지고, 데이터 파일 안에서도 암호화돼서 파일을 직접 열어도 읽을 수 없어요.
